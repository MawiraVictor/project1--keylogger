# Safe keyboard demo

This repository was previously a keystroke logging sample, which is a malicious pattern and is not acceptable for public or shared code.

The project has been sanitized to remove the harmful behavior. It now contains a safe, non-invasive demo that does not capture, log, or transmit keyboard input.

## What this version does

- Shows a safe example of a keyboard event listener pattern.
- Does not store keystrokes to disk.
- Does not transmit any user input.
- Uses a harmless stub for educational and demonstration purposes only.

## Important

Do not use this repository to collect personal or sensitive information. Any real keystroke capture or credential logging is unethical and potentially illegal.
